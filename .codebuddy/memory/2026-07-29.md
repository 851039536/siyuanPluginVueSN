## WorktreeOps 与 RepoOps 解析修复（3 项）

### #1 WorktreeOps 重命名文件 porcelain 解析修复 + #3 局限注释
- **核心**：原先先对整行去引号再按 ` -> ` 拆分，重命名含特殊字符时 `"old" -> "new"` 被整体 unquote 导致引号错位
- 修复：新增 `unquote()` 辅助函数，先拆分 ` -> ` 再分别对 old/new 路径去引号；非重命名路径统一走 `unquote(rawPath)`
- 对 `"` 开头结尾的字符串才 `slice(1,-1)`，处理 `"` 内嵌 `"` 场景（如 """"）
- 补注释：基于 `core.quotepath=false` + 文本解析，路径含换行等极端字符仍有局限，未用 `-z` 是权衡

### #5 WorktreeOps commit log 格式依赖注释
- `getCommitLog` 的 `%h%n%s%n%an%n%ar%n%aI` 上方补注释："依赖 %s(subject) 单行，勿加入 %b(body) 等多行字段，否则 5 行固定切分错位"

### #7 RepoOps scanForGitRepos 同步递归扫描加边界
- 队列项从裸 `string` 改为 `{ dir, depth }`，新增 `MAX_DEPTH=8`、`MAX_RESULTS=500` 常量
- 入队子目录时检查 `depth < MAX_DEPTH`，找到结果后检查 `results.length >= MAX_RESULTS` break
- 顶部注释说明边界值用途（防止扫描大目录树同步阻塞渲染进程）
