# 2026-08-01 工作记录

## 修复 release.js 两个 git 相关 bug

### 问题
1. `pnpm release:major` 报 `fatal: tag 'v2.0.0' already exists` — 串联命令 `git add && git commit && git push && git tag` 中 tag 已存在导致整体失败，但文件已提交推送
2. `pnpm release:patch` 报 `fatal: 'origin' does not appear to be a git repository` — 硬编码 origin，但用户远程名是 gitee

### 修改内容
- 新增 `execAsync(cmd)` — Promise 化 exec，失败时 reject 带 stderr
- 新增 `checkTagExists(tag)` — 用 `git tag -l` 检查标签是否存在
- 重构第 185-203 行为分步 async 流程：
  1. add + commit
  2. git push
  3. 检查标签 → 不存在则创建，已存在则跳过
  4. 调用已有的 `getPushRemote()` 获取实际远程名后推送标签
- lint 通过，0 error
