## 补充修复：vue-diff 第三方组件类名覆盖失效（DiffPreview 字号仍偏大的真正根因）
上一轮 Token 化后用户反馈"页面还是没变化"，深入排查 node_modules/vue-diff 源码后定位真正根因：

**vue-diff 实际 DOM 类名（与旧选择器完全不同）**：
- 根容器：`.vue-diff-wrapper`（不是 `.vue-diff`！旧代码 `:deep(.vue-diff)` 全部匹配不到元素，纯死代码）
- 查看器：`.vue-diff-viewer`（**第三方硬编码 `font-size:16px; line-height:1.5`**，定义在 dist/index.css 第 1 行，这是字号偏大的直接来源）
- 行：`.vue-diff-row` → `.lineNum` + `.code`；增删行：`.vue-diff-cell-added` / `.vue-diff-cell-removed`（不是 diff2html 的 `.d2h-*` 类！旧颜色覆盖 `.d2h-del/.d2h-ins/.d2h-info/.d2h-file-header/.d2h-tag` 也全是死代码）

**修复**（仅改 `src/features/aiContentGenerator/styles/index.scss` 的 `.diff-viewer-wrapper` 区块）：
1. `:deep(.vue-diff)` → `:deep(.vue-diff-wrapper)` 根容器 + `font-size: $font-size-xs`
2. 新增 `:deep(.vue-diff-viewer)` 覆盖第三方 16px → `$font-size-xs !important`、line-height 1.5 → `$line-height-normal !important`
3. 全后代 `:deep(.vue-diff-viewer *)` `font-size: inherit !important`（含行号 .lineNum 的 .9em 相对值）
4. 行号列 `.vue-diff-row .lineNum` 单独降为 `$font-size-2xs`
5. hljs 背景 `background: transparent !important` 融入 b3 主题
6. 颜色覆盖类名改为 `.vue-diff-cell-removed/.vue-diff-cell-added`，删除所有 `.d2h-*` 死代码

**注意：`src/features/textDiff/styles/TextDiff.scss` L320-328 存在同样的 `.vue-diff` 选择器错误**（`:deep(.vue-diff)` + `:deep(.vue-diff *)`），textDiff 页面同样受 16px 影响。本次未改 textDiff（用户只要求 DiffPreview），后续如需可同样修复。验证：read_lints 0 error。
