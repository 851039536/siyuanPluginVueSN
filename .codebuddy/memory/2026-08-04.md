## quickNote 模块新增 AI 润色功能 + 冗余清理

为用户确认的需求（两个位置都加润色按钮 + 润色结果回填输入框）完成了 quickNote 模块改造：

1. **新增 `composables/useAiPolish.ts`**：AI 润色 composable，导出 `PolishError`（错误码 `NO_API_KEY`/`CALL_FAILED`）与 `useAiPolish(plugin)`（返回 `{ polishing, polish }`）。`polish(text, onChunk)` 走 `getApiConfigFromPlugin` + `callAISmart` 流式（systemPrompt 润色角色、temperature 0.5、maxTokens 1000、enableThinking false），内部有并发锁，API Key 缺失抛 NO_API_KEY。

2. **index.vue**：新增速记区 textarea 下加 `.add-area__actions` 操作行，左侧 AI 润色按钮（SiButton variant=secondary + sparkles 图标 + loading 态），点击后缓存原稿 → 清空 draft → 流式回填 → 失败恢复原稿并经 `@/api` 的 `pushMsg` 提示（错误码区分文案）。同时冗余清理：抽 `syncPosition()` 合并三处 `props.manager.getPosition()` 重复调用、`props.i18n.deleteConfirm` 统一为解构 `i18n`。

3. **NoteItem.vue**：props 新增 `plugin: Plugin`（父层透传），编辑态操作栏加润色按钮，流式回填 editDraft，同一套失败恢复 + pushMsg 逻辑。文件头注释同步更新（不再是纯展示组件）。

4. **样式去重**：index.scss 将 `.close-btn` 泛化为共享类 `.qn-icon-btn`（20x20 图标按钮，含 hover/disabled/`--danger` 变体），index.vue 头部 3 按钮与 NoteItem.vue 5 按钮全部改用；NoteItem.scss 删除重复基础样式仅保留注释。新增 `.add-area__actions`（space-between 布局）。

5. **i18n**：zh_CN/en_US quickNote.json 各新增 polish/polishing/polishFailed/polishNoApiKey 四键（已对齐）。

6. README.md 补充 AI 润色功能说明与 useAiPolish 目录职责。

验证：read_lints 0 error。待用户自行运行 `pnpm i18n:verify` 确认键对齐。

## gitPush 模块新增 AI 错误分析功能（推送/拉取失败时）

为 gitPush 的 OutputPanel 日志区新增「AI 分析」按钮，点击弹出流式 AI 分析弹窗，分析 Git 失败日志并输出原因/解决方案/预防建议。

1. **GitPushManager.ts**：新增 public `getAiConfig()`，返回 `getApiConfigFromPlugin(this.plugin)`（统一走 `@/utils/aiApi`），供卡片级 AI 弹窗读取超级面板 AI 配置。
2. **新增 `components/list/AiErrorAnalysisDialog.vue`**：自包含弹窗（props 仅 i18n/projectName/action/entries），Teleport 到 body，注入 `CARD_SERVICES_KEY` 取 manager。流式调用 `callAISmart`（systemPrompt Git 专家、temperature 0.3、maxTokens 1024、onChunk 逐字渲染），失败日志折叠区（默认展开，截断 4000 字符防 token 膨胀），复制结果 2s 反馈，Esc/遮罩关闭，打开自动分析，支持重新分析。无 API Key 时明确提示。
3. **OutputPanel.vue**：新增 `i18n/projectName/action` props，`hasFailed` computed（`!ok && !skipped`）控制按钮显隐，按钮在面板底部右对齐（`.gp-output-ai`/`.gp-output-ai-btn` 样式入 index.scss）。
4. **ProjectCard.vue**：为 OutputPanel 传 i18n/project-name/action（action 用 outputPanels 的 key）。
5. **i18n**：zh_CN/en_US gitPush.json 各新增 9 键（aiAnalyze/aiAnalyzeTitle/aiAnalyzeRetry/aiAnalyzeCopy/aiAnalyzeErrorLog/aiAnalyzing/aiAnalyzeFailed/aiAnalyzeNoKey/aiAnalyzeFooterHint），已对齐。
6. **README.md**：组件树 list/ 更新为 11 个（含 AiErrorAnalysisDialog），补充 AI 错误分析功能说明与 getAiConfig 方法。
7. **样式**：新增 AiErrorAnalysisDialog.scss（Codex 风格，`.gp-ai-*` 前缀，全设计 Token，复用 gp-md-content 排版并降级字号为 xs 适配弹窗窄栏）。

验证：read_lints 0 error。图标均在离线 mdi 全集内（`mdi:auto-fix` 已在 icons.ts 注册）。待用户自行验证 4 项检查（lint/i18n:verify/validate:icons/tsc）。
