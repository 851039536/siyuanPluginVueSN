## gitPush 统计报告幽灵文件修复（reportMetrics）
修复统计报告显示已删除文件（LOC 为空 `-`）的问题。根因：`aggregateFileStats` 基于 `git log --numstat` 聚合历史所有被触碰过的文件，git 历史不因文件删除而消失，已删除文件进入 `fileMap`；`countFileLines` 对已删除文件 `statSync` 抛 ENOENT 返回 null，UI 显示 `-`。

改动（`src/features/gitPush/reportMetrics.ts`）：
1. 新增 `fileExistsInRepo(project, filePath)` 导出函数 —— `statSync().isFile()` 做当前磁盘存在性检查
2. `buildReportData` 的 `rankedFiles` 构造处追加 `.filter(([path]: [string, FileAgg]) => fileExistsInRepo(project, path))` 剔除幽灵文件

效果：技术债务表/热点榜单/analyzedFiles 统计只含当前存在的文件；作者贡献度 `filesTouched` 不变（历史事实）。lint 0 error。
