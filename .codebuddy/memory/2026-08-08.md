## 文件详情弹窗：新增 git diff 代码显示（2026-08-08）

用户反馈：保留当前指标显示的基础上，额外展示文件的 git diff 代码变更内容。

### 改动文件
1. `types/report.ts` — `FileStatRow` 新增 `diffContent: string | null` 字段（null=获取失败/不适用）
2. `reportMetrics.ts` — 新增 `fetchFileDiff(project, filePath)` 函数：使用 `getNodeProcessModules().child_process.execFileSync` 同步执行 `git log -p --max-count=5 -- <file>`，截断上限 5000 字符；`buildReportData` 中 `fileDetailsMap` 每条记录调用 `fetchFileDiff` 填充 `diffContent`；`base` 构造点补 `diffContent: null`
3. `FileDetailModal.vue` — 修复误删的 `Icon` 导入；指标网格下方新增 `<!-- 变更详情 -->` 区域：`v-if="fileStat.diffContent"` 条件渲染，`<pre class="gpr-fm-diff">` 展示原始 diff
4. `FileDetailModal.scss` — 卡片加宽（420→680px）；新增 `.gpr-fm-diff-section` / `.gpr-fm-diff` 样式：等宽 10px、暗色底边框、最大高度 280px 可滚动
5. i18n 分片 — 新增 `reportFileDetailDiff` = "变更详情" / "Code Changes"

### 性能考量
- `fetchFileDiff` 为同步 `execFileSync`，每个文件跑一次 `git log -p --max-count=5`（与 `countFileLines` 的同步 fs 读策略一致）
- 文件数上限为 作者数×3（通常 ≤30），单文件 diff 提取约 10-50ms，总量 < 1s
- 截断上限 5000 字符 + 2MB maxBuffer 防止巨型文件 OOM
- diff 仅对 `fileDetailsMap` 中的 topFiles 条目执行（债务/热点行 `diffContent: null`）
