## gitPush 报告移除"质量评分"（方案 C：参考 git-fame，不做综合评分）

用户选择方案 C——移除代码贡献度表的单一"质量评分"列及启发式公式，仅保留原始多维指标（提交次数/代码行数/净增/平均提交大小/提交频率/文件数/活跃天数），让用户自行判断。

### 改动文件
1. `src/features/gitPush/types/report.ts` — 移除 `QualityGrade` 类型、`GRADE_META` 常量；`AuthorReportRow` 移除 `quality`/`grade` 字段；`CodeReportData.teamOverview` 移除 `avgQuality`
2. `src/features/gitPush/types/index.ts` — 移除 `GRADE_META`、`QualityGrade` 重导出
3. `src/features/gitPush/reportMetrics.ts` — 移除 `qualityScore()`/`qualityGrade()` 函数及 import；`aggregateAuthorStats()` 移除 quality/grade 计算；`buildReportData()` 移除 avgQuality 聚合与赋值；`buildEmptyReport()` 同步移除
4. `src/features/gitPush/components/report/AuthorContributionSection.vue` — 移除质量评分表头列与 `<td>` 渲染；展开行 `colspan` 10→9（列数从 10 减为 9）；移除 `GRADE_META` import 及 gradeLabel/gradeColor/gradeBg/stars 派生值
5. `src/features/gitPush/components/report/TeamOverviewSection.vue` — 移除"平均代码质量"卡片（overviewCards 第 4 项）
6. `src/features/gitPush/styles/AuthorContributionSection.scss` — 移除 `.gpr-grade-chip`、`.gpr-stars` 样式；`TeamOverviewSection.scss` 移除孤立的 `.gpr-card--warn` 样式
7. i18n 4 个文件（`zh_CN/gitPush.json`、`en_US/gitPush.json`、`zh_CN.json`、`en_US.json`）— 移除 `reportAvgQuality`/`reportQualityCol`/`reportGradeS~D` 共 8 个键

### 经验教训
并行执行多个 `replace_in_file` 编辑**同一文件**的多个不同区块时，发生了部分编辑被覆盖/丢失（尤其 i18n JSON 与 report.ts 的多个独立替换），导致中间状态不一致（`qualityScore` 引用残留、`GRADE_META` 重复）。最终靠 search_content 全量扫描 + 逐文件串行重读重改才收敛。**教训：同一文件的多个编辑务必串行执行，或一次 replace 覆盖完整连续区块。**

- `read_lints` gitPush 目录 → 0 error
