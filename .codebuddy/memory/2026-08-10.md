## ReviewPanel 新增五轴雷达图

为"分项评分"折叠区新增纯 SVG 雷达图（不引入 chart.js Radar），与条形图上下互补展示：

- 新增 `components/ReviewRadarChart.vue` + `styles/ReviewRadarChart.scss`
- 五轴等分 360°（accuracy/structure/quality/format/coverage），3 层同心网格（5/8/10 分档），数据多边形按平均分等级着色，数据点按各自维度等级着色
- 关键几何决策：MAX_RADIUS=50、轴标签偏移 18、分数标签偏移 6、viewBox="-110 -85 220 170"
- 防碰撞方案：分数标注用**反向锚点**（scoreAnchorByCos，右轴 end/左轴 start 向圆心展开），轴标签用方向锚点 + baseline（顶部 auto/底部 hanging/水平 middle），避免高分时数据标签与轴标签重叠
- 颜色复用 `scoreLevel()` 的 high/mid/low 语义色（success/warning/error），字号用 $font-size-2xs，分数用 $vp-mono 等宽字体
- 修改 `ReviewPanel.vue`：模板条形图上方插入 `<ReviewRadarChart :scores="reviewResult.detailedScore" :labels="scoreLabelMap" :get-level="scoreLevel" />`，import 一行
- 无 i18n / 类型变更。lint 0 错误。

## 审查面板迁移至独立 Tab + 直接审查按钮

用户需求：将 ReviewPanel 从内联位置迁移到"对比"旁边的独立"审查"Tab；审查冗余；新增醒目"直接审查"按钮。

### 改动清单
- **useReview.ts**：`performReview(override?, force = false)` 新增 `force` 参数，`force=true` 时跳过 `enableReview` 开关检查
- **index.vue**：新增 `handleDirectReview()`（调用 `performReview(undefined, true)`），模板绑定 `@directReview`
- **MainContentArea.vue**（核心重构）：
  - `viewMode` 类型 `"preview" | "diff"` → `"preview" | "diff" | "review"`
  - 对比按钮旁新增"审查"Tab 按钮（`#iconSparkles` 图标，`!generatedContent` 时禁用）
  - ReviewPanel 从 result-header 下方内联位置迁入 `result-content` 的 `v-else-if="viewMode === 'review'"` 分支，含空态提示（`reviewTabEmpty`）
  - 删除旧幽灵"重新审核"按钮（`v-if="!isGenerating && generatedContent && !isReviewing && !reviewResult"` 的 ghost 按钮）→ 被新的"直接审查"primary 按钮取代（`#iconSparkles` + 文字，仅 `isGenerating/isReviewing` 时隐藏）
  - 新增 `watch([isReviewing, reviewResult])` 审核发起或结果就绪时自动切到 review Tab
- **styles/index.scss**：新增 `.review-tab`（flex column + overflow-y auto + `$spacing-2` 右留白）、`.review-tab-empty`（居中空态，`$font-size-2xs`）、`.review-tab-empty-icon`
- **i18n**：zh_CN/en_US 各新增 4 键（`reviewTab`/`directReview`/`directReviewTitle`/`reviewTabEmpty`），并清理冗余键 `reviewReReviewTitle`（旧幽灵按钮删除后无引用）

### 关键决策
- "直接审查"用 `variant="primary"`（与"应用"同色，但位置在复制按钮后、有 `#iconSparkles` 图标区分）
- 自动切 Tab 用 watch 数组（isReviewing || reviewResult 任一为真即切 review），与 `watch(isGenerating)` 重置 preview 的既有逻辑共存
- 审查 Tab 空态无结果时显示 `reviewTabEmpty` 提示，不渲染 ReviewPanel
- codex-ui-style-guide 技能审查通过：全部 Token 化（`$spacing-2`/`$font-size-2xs`/`$line-height-normal`/`var(--b3-theme-*)`），无 box-shadow/硬编码
- lint 仅剩 ReviewRadarChart.vue 预先存在的 `ScoreKey` 未使用警告，非本次引入。用户需自行运行 pnpm lint + npx tsc --noEmit + pnpm i18n:verify 终验
