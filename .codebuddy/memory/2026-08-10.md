# 2026-08-10

## ReviewPanel.vue 质量评审重构

对 `src/features/aiContentGenerator/components/ReviewPanel.vue` 及其 `ReviewPanel.scss` 完成质量评审驱动重构，加载了 codex-ui-style-guide 技能审核。

### 模板层
- 新增 `SvgIcon.vue` 辅助组件（components/SvgIcon.vue），封装 5 处重复的内联 `<svg><use>` 模式。props：`name`（icon 引用）+ `size`（默认 12）；`inheritAttrs: false` + `v-bind="$attrs"` 支持 class 透传（chevron 的 expanded 类合并）。
- 5 处内联 SVG 全部替换为 `<SvgIcon name="#iconXxx" :size="10|12" />`。

### Script 层
- 新增 `SEVERITY_LABEL_MAP: Record<IssueSeverity, string>` computed，将严重度"高/中/低"映射到 i18n 键，`filterOptions` 的 label 不再直接用中文枚举值，与"全部"按钮统一走 i18n。

### i18n
- zh_CN + en_US 的 aiContentGenerator.json 各新增 3 键：`reviewSeverityHigh`(高/High)、`reviewSeverityMid`(中/Mid)、`reviewSeverityLow`(低/Low)。
- `pnpm i18n:verify` 通过，3509 键全同步。

### SCSS 合规（ReviewPanel.scss）
- 所有硬编码 border-radius:3px → `$radius-sm`(4px)；border-radius:2px → `$spacing-2px`(2px)。
- gap:8px → `$spacing-2`；gap:4px → `$spacing-1`；gap:3px → `$spacing-px`；gap:5px → `$spacing-1`；gap:2px → `$spacing-2px`。
- padding:2px 7px → `$spacing-2px $spacing-2`；padding:0 4px → `0 $spacing-1`。
- 6px 间距无精确 token，保留字面值并加 `// 6px 无精确 token，保留` 注释（gap:6px、padding 侧向 6px、badge 内 6px）。
- lint 0 错误。用户需自行运行 pnpm lint 和 npx tsc --noEmit 终验。
