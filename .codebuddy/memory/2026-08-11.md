## 项目列表空状态 Bug 修复 + editingProject 状态泄漏修复（1 个文件）

用户反馈：新增项目后在项目列表看不到，但待办关联下拉和复盘看得到。

审查发现 2 个问题：

1. **`project-list__empty` 空判断与渲染数据源不一致**（根因）：
   - 第 238 行 `v-if="projects.length === 0"` 判断的是全量项目，但列表渲染的是 `activeProjects`（排除 completed）
   - 当所有项目都是 completed 状态时：空提示不显示（projects > 0），列表也不显示（activeProjects 为空）→ 一片空白
   - 修复：`projects.length === 0` → `activeProjects.length === 0`

2. **`editingProject`/`editingTodo` 状态泄漏**（潜在 Bug）：
   - 进入编辑模式后切换 Tab，编辑状态不会被清空
   - 下次回到原 Tab，表单仍回填旧数据，用户保存会 update 旧条目而非 add 新条目
   - 修复：新增 `watch(activeTab, () => { editingProject = null; editingTodo = null })` 在 Tab 切换时自动清空
   - import 补充 `watch`

lint 零错误。仅改动 `index.vue`。
