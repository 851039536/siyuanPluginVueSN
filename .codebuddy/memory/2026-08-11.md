## quickNote 项目跟进 Tab — 新增编辑修改功能（4 个文件）

用户反馈项目跟进 Tab 只有新增，无法修改已有项目。打通"卡片编辑按钮 → 表单回填 → 保存更新"链路：

1. **ProjectItem.vue**：卡片头部 actions 新增编辑按钮（铅笔图标），emit `edit` 事件
2. **ProjectForm.vue**：新增 `editingProject` prop（非 null 为编辑模式）；`watch(editingProject, { immediate })` 自动回填/清空表单；提交 payload 新增可选 `id`（编辑模式携带）；新增 `cancel` emit；新增/编辑共用组件，模式通过 prop 区分
3. **index.vue**：管理 `editingProject: Ref<ProjectItemType | null>` 状态；新增 `startEdit(project)`、`handleProjectSubmit(payload)`（id 有→update、无→add）、`handleCancelEdit`（置 null→触发 watch 清空表单）
4. **ProjectForm.scss**：保存按钮与 add-btn 合并选择器；新增取消按钮 `.qn-proj-form__cancel-btn`（灰色边框透明底 + `margin-right: auto` 左对齐）

数据流：ProjectItem emit edit → index.vue startEdit 设 editingProject → ProjectForm watch 回填 → 用户修改后保存 → index handleProjectSubmit 调 update + 置 null → ProjectForm watch 清空表单。

i18n 无需改动（edit/save/cancel 键已存在）。lint 零错误。类型冲突修复：导入 `ProjectItem as ProjectItemType`（避免与组件 `import ProjectItem` 重名）。

## 项目列表空状态 Bug 修复 + editingProject 状态泄漏修复（1 个文件）

用户反馈：新增项目后在项目列表看不到，但待办关联下拉和复盘看得到。

审查发现 2 个问题：

1. **`project-list__empty` 空判断与渲染数据源不一致**（根因）：
   - 第 238 行 `v-if="projects.length === 0"` 判断的是全量项目，但列表渲染的是 `activeProjects`（排除 completed）
   - 当所有项目都是 completed 状态时：空提示不显示（projects > 0），列表也不显示（activeProjects 为空）→ 一片空白
   - 修复：`projects.length === 0` → `activeProjects.length === 0`

2. **`editingProject`/`editingTodo` 状态泄漏**（潜在 Bug）：
   - 进入编辑模式后切换 Tab，编辑状态不会被清空
   - 下次回到原 Tab，表单仍回填旧数据，用户保存会 update 旧条目而非 add 新条目
   - 修复：新增 `watch(activeTab, () => { editingProject = null; editingTodo = null })` 在 Tab 切换时自动清空
   - import 补充 `watch`

lint 零错误。仅改动 `index.vue`。
