## 代码块美化也支持两个内置字体
用户要求 `CodeBlockSettings.vue`（代码块美化）也把这两个内置字体（霞鹜文楷 + 新晰黑 Code）加入代码字体预设。

**改动**（`src/features/generalSettings/components/CodeBlockSettings.vue`）：
1. `presetFonts` 从**纯字符串数组**（`["Consolas", ...] as const`）改为**对象数组** `{ value, label, builtin? }`：原 5 个等宽字体（Consolas/Courier New/JetBrains Mono/Cascadia Code/Hack）+ 新增 `{ value: "NeoXiHei Code", label: "新晰黑 Code (NeoXiHei)", builtin: true }` 和 `{ value: "LXGW WenKai", label: "霞鹜文楷 (LXGW WenKai)", builtin: true }`
2. 新增 `isBuiltinCodeFontSelected` computed（`BUILTIN_FONTS.some(...)`），**注意必须放在 `settings` ref 定义之后**（TS 禁止 used before declaration）
3. `presetCodeFont` computed 的 `get` 从 `presetFonts.includes(family)` 改为 `presetFonts.some(f => f.value === family)`
4. 模板 `<select>` 的 `<option>` 循环改为 `:key="f.value"` `:value="f.value"` 显示 `{{ f.label }}`
5. 字体族行下方新增内置字体提示 `<p v-if="isBuiltinCodeFontSelected">`（复用 `i18n.builtinFontHint` + `checkCircle` 图标）
6. **CodeBlockSettings.scss** 新增 `.builtin-font-hint` / `.builtin-font-hint-icon` 样式（与 DocumentFontSettings.scss 一致）

**生效机制**：`applyCodeBlockStyle` 中 `font-family: '${codeSettings.codeFontFamily}', monospace !important;` 直接拼接 family 名，配合全局已注入的 `@font-face` 即可生效，无需额外逻辑。

**注意**：`presetFonts` 是组件内常量（仅 1 处使用，未提取到 types/utils——符合 Rule of Three 不提前抽象）。
