## 构建报错修复：8 个 .scss 缺 @use 导入

用户运行 vite build 报 `[vite:css] [sass] Undefined variable`（shortcut/DeleteConfirmDialog.scss 的 `$font-size-xs`）。根因：本次字体修复把硬编码 px 换成 Token，但部分文件原本纯用硬编码 + `var()`，**没有 `@use '@/variables.scss' as *;` 导入**。

扫描「使用 $ 变量但无 @use」后修复 8 个文件（均在文件头部补 `@use '@/variables.scss' as *;`）：
1. `shortcut/styles/DeleteConfirmDialog.scss`
2. `shortcut/styles/ShortcutCard.scss`
3. `shortcut/styles/ShortcutDialog.scss`
4. `shortcut/styles/ShortcutGrid.scss`
5. `video/styles/VideoListItem.scss`
6. `video/styles/VideoToolbar.scss`
7. `imageCreation/styles/CodeImageStyles.scss`
8. `toolCollection/tools/unitConverter/styles/index.scss`

**关键经验**：替换硬编码为 Token 时，必须确认目标文件已有 `@use '@/variables.scss' as *;`。原本纯用硬编码的文件（无任何 Token）不会导入变量，替换后必然报 Undefined variable。修复前应先用扫描排查「使用 $ 但无 @use」的文件。扫描 PowerShell 命令（用 .NET API 避免编码问题）：`Get-ChildItem -Path 'src' -Filter '*.scss' -Recurse | ForEach-Object { $c = [System.IO.File]::ReadAllText($_.FullName); if ($c -match '\$[A-Za-z_]' -and $c -notmatch '@use' -and $_.Name -notmatch '^_' -and $_.Name -ne 'variables.scss') { $_.FullName } }`。
