## prompts 模块 UI 重构与冗余清理

完成了 prompts（提示词库）模块的 UI 布局重构与冗余清理，遵循 Codex UI 规范。

### 布局重构
- 主面板从「顶部横向分类 chips + 3 列 CSS columns 瀑布流」改为「左侧分类侧边栏 + 右侧内容区」两栏布局

3. 提取 `@mixin form-label`，消除 `.vp-form-group label` 与 `.vp-form-label` 的重复样式
4. 删除 `$modal-large-max-width: 1200px`（未引用）、`@use "sass:color"`（未使用）
