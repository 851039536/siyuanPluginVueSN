# 2026-08-20

## toolCollection 新增独立窗口承载（双形态）

为 toolCollection 模块实现了「独立窗口打开」能力，参考 minimalBrowser 的 addTab + openWindow 双形态承载方案。

### 改动文件（4 个源码 + 2 个 i18n + README）

1. **types/index.ts**：新增 `TOOL_COLLECTION_TAB_TYPE` 常量 + `ToolCollectionManager` 类
   - `registerTabModel()`：`plugin.addTab({ type, init, destroy })` 注册自定义页签（模块级 `tabRegistered` 防重复注册）
   - `openFloating()`：先 `openTab` 创建/聚焦主窗口页签 → `openWindow({ width: 1280, height: 800, tab })` 移入浮动窗口
   - `mountPanel()`：以 `mode="tab"` 挂载 index.vue（容器补 `vp-dock-root` 类 + 全高）

2. **index.vue**：支持 `mode` prop（`"overlay" | "tab"`，默认 overlay）+ `visible` 改为可选
   - overlay 模式保留原底部面板行为；tab 模式隐藏拖拽手柄/尺寸调整/关闭按钮
   - 头部新增「在独立窗口打开」按钮（`isFloating` = `getFrontend() === "desktop-window"` 时隐藏）
   - `openFloatingWindow()` 经 `(plugin as any).__toolCollection.openFloating` 调度，并先关闭底部面板避免双实例
   - 键盘导航：`visibleForNav = computed(() => props.visible?.value ?? true)` 适配 tab 模式无 visible

3. **index.ts**：`registerToolCollection` 内实例化 Manager、`plugin.addIcons` 注册 `iconToolCollection`（2x2 网格 SVG）；`__toolCollection` 挂载点改为 `{ openFloating, destroy }`（destroy 同时调 manager.destroy + unregisterToolCollection）

4. **styles/index.scss**：新增 `.tool-collection-overlay.tab-mode`（static + flex 全高）与 `.tool-collection-panel.tab-mode`（取消 fixed 底部定位）；`.header-close/.header-float` 合并样式；tab 模式 `.header-float` 靠右

5. **i18n**：zh_CN/en_US toolCollection.json 的 `toolCollectionPanel` 新增 `openFloatingWindow`（在独立窗口打开 / Open in floating window）

6. **README.md**：补充架构说明、双形态承载章节

### 关键设计

- 纯官方 API（addTab/openTab/openWindow），关闭浮动窗口页签自动移回主窗口，无需反向操作
- 与 minimalBrowser 一致：types/index.ts 承载 Manager（与 index.vue 形成单向运行时导入 + 类型级反向引用，Vite 无问题）
- lint 0 error；i18n:verify 需用户自行验证（两个分片文件已同步加键）

## gitPush 加入独立窗口承载（Dock + tab 双形态）

沿用刚文档化的「独立窗口承载」规则，为 gitPush（Dock 面板）加入独立窗口能力。改动 4 个源码 + 2 个 i18n + README：

1. **GitPushManager.ts**：类内新增独立窗口承载逻辑（不另建 Manager 类，gitPush 已有门面）
   - 模块级 `GIT_PUSH_TAB_TYPE = "git-push-tab"` + `tabRegistered` 防重复注册
   - constructor 调用 `registerTabModel()`（addTab 需同步注册）
   - `mountTabPanel()` 以 `mode: "tab"` 挂载 index.vue；`unmountTabPanel()` 清理
   - `openFloating()`（public）：openTab → openWindow({width:1280,height:800,tab})
   - 提取 `getPanelI18n()` 供 init() 与 tab 挂载复用
   - `destroy()` 增加 unmountTabPanel()

2. **index.vue**：props 新增 `mode?: "dock" | "tab"`；`isFloating` computed（getFrontend()==="desktop-window"）+ `openFloatingWindow()`（调 manager.openFloating()）；PanelHeader 绑定 `:is-floating` + `@open-floating`

3. **PanelHeader.vue**：props 新增 `isFloating`、emits 新增 `openFloating`；「设置」按钮后新增「在独立窗口打开」按钮（mdi:dock-window，v-if="!isFloating"）

4. **i18n**：zh_CN/en_US gitPush.json 新增 `openFloatingWindow`（在独立窗口打开 / Open in floating window）

5. **README.md**：功能列表 + 目录结构 + 使用步骤三处补充

注意：GitPushManager 是门面类（~450 行），新增的独立窗口逻辑直接内联在类中而非独立 Manager（与 toolCollection 的独立 ToolCollectionManager 不同），因为 gitPush 的 manager 本身就是对外 API 门面。lint 0 error。
