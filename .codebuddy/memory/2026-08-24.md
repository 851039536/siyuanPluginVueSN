## 新增功能：灵感生成器（ideaGenerator）

为用户新增「灵感生成器」功能模块，独立浮动窗口承载（复用 minimalBrowser 的 addTab + openTab + openWindow 双形态模式）。核心能力：
- 预设 6 个开发方向分类（桌面工具/命令行脚本/思源插件/Web 应用/效率工具/自动化）+ 可选关键词定向生成
- `callAI` 单次非流式批量生成 5 条灵感（system prompt 引导 Markdown 列表 `- **标题**：描述`，`parseIdeasResponse` 解析 + 行拆分兜底）
- 三种选择动作：展开查看 / 一键复制（`copyToClipboard`）/ `callAIStream` 流式细化为完整技术方案（需求说明/技术栈/实现要点/扩展方向），支持 AbortController 取消
- 快捷键 `⌃⌥I` + 超级面板 action（`openIdeaGenerator` 事件联动）+ `addIcons` 注册 iconLightbulb Tab 图标

新增 14 个文件（types/index.ts + utils.ts + index.ts + index.vue + composables/useIdeaGenerator.ts + 3 子组件 + 5 SCSS + README），修改 7 个注册文件。完整走 8 步注册清单。

设计要点：不持久化（无 storage.ts）、双 AbortController 防竞态、IDEA_CATEGORIES 共享常量放 types/、resolveI18nLabel 点路径解析分类标签（utils.ts 纯函数，避免 composable 与组件重复）。

验证：read_lints 0 错误。`pnpm lint` / `pnpm i18n:verify` / `pnpm validate:icons` / `npx tsc --noEmit` 由用户自行验证。

## 迭代：ideaGenerator 新增「引导发散」模式 + 修复右侧遮挡

用户反馈"当前功能太简陋，参考 github（BrainBoost/Mind-Map-Wizard 类），希望输入主题 → AI 生成分类选项让我选 → 一步步引导 → 灵感发散"。确定需求：AI 动态多轮引导 + 先方向后灵感 + 保留预设分类一键生成（双模式并存）。

实现：
- `index.vue` 顶部加模式 Tab（快捷生成 / 引导发散，`activeMode: "quick" | "guide"`）
- 新增 `composables/useGuideDiverge.ts`：引导状态机 `GuideStage = "input" | "guiding" | "ideas"`，维护 topic/directions/steps/ideas；方法 startDiverge/selectDirection/regenerateDirections/stepBack/divergeIdeas/restart
- 新增 `composables/useIdeaDetail.ts`：提取展开/复制/流式细化公共逻辑（两模式复用），`refineIdea(idea, contextLabel)` 接收分类标签或发散路径作为上下文；RefineStatus 类型移至此
- `types/index.ts` 新增 GuideDirection/GuideStage；`utils.ts` 新增 buildDirectionsPrompt/buildDivergePrompt/parseDirectionsResponse，并泛化 parseIdeasResponse 为底层 parseOptionList（方向与灵感共用）
- 新增组件 GuideDiverge.vue（三态：主题输入/方向深挖/灵感结果）+ DirectionCard.vue + 两个 SCSS
- 右侧遮挡修复：`.ig-body` 加 flex-wrap，`.ig-detail` 由固定 width:300px+shrink:0 改为 flex:0 1 300px + min-width:280px（窄容器换行而非溢出被裁切）

设计要点：双模式状态互不共享、双 AbortController 防竞态、方向与灵感共用 parseOptionList 解析器、路径面包屑可视化。read_lints 0 错误，i18n 中英键对齐。
