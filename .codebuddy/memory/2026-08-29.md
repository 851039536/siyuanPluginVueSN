## 批量修复"点击没反应"修复（同日，第三轮）

用户反馈批量修复点击无反应。根因排查与修复：

1. **根因 A（主要）**：批量修复按钮 `:disabled="selectedKeys.size === 0 || fixing"`——未勾选任何违规时按钮禁用但 `vp-btn--ghost` 禁用态视觉不明显，用户直接点击毫无反馈
2. **根因 B**：选中集合用 `ref<Set<string>>`，Vue 3 对 Set 的响应式代理（size/迭代依赖收集）边界较多，存在勾选状态不可靠风险

修复：
- `useBatchCommitFix.ts` 改用**对象映射** `selectedMap = ref<Record<string, boolean>>` + `selectedCount` computed + 提供 `isSelected`；`fixSelected` 用 `violations.value.filter(v => selectedMap.value[violationKey(v)])` 直接匹配
- `ViolationListSection.vue`：按钮 `:disabled` 仅保留 `fixing`（不再因无选中禁用）；未勾选时点击显示引导提示 `batchNotice`（i18n 键 `ruleCheckSelectHint`，警告色样式 `.grc-batch-result--hint`）；watch 数据源变化时清空选中+提示+结果
- i18n 中英新增 `ruleCheckSelectHint`（"请先勾选要修复的违规项"）

read_lints 0 error。
