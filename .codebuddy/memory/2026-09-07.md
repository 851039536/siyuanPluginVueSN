## gitPush StatsView UI 布局重构
- 需求：统计视图布局不好看、排版不舒服。澄清确认 4 痛点（瀑布流切割突兀/区块无卡片感/间距密度/总览卡片单调），方向选「区块卡片化 + 自适应网格」，总览卡片一并重做
- 实现（纯 UI，零数据流/注册链/i18n 改动，4 文件）：
  1. `StatsView/index.vue`：`.gp-stats-masonry`（CSS 多列瀑布）→ `.gp-stats-grid`（auto-fit minmax(21rem,1fr)），三个表格区块（待处理/平台矩阵/链接审计）加 `gp-stats-section--full`（grid-column: 1/-1 全宽），窄 Dock 自动单列
  2. `StatsPanel.scss`：`.gp-stats-section` 升级边框卡片（surface 底 + border + $radius-base + $spacing-3 内边距 + 0.12s hover）；总览卡片重写为「语义色图标块 + 数值 + 大写标签」三段式，与 _mixins.scss 的 stat-card/stat-card-value/stat-card-label mixin 合流消除重复；表格行 hover 由 surface 改 primary-lightest（卡片底已是 surface 原方案不可见）；覆盖率轨道由 surface 改 theme-background（同上对比度问题）；chips gap/table 行 padding Token 化
  3. `OverviewCards.vue`：配置加 icon 字段（folder-multiple/cloud-check/cloud-upload/file-edit/star/archive），新增 `gp-stat-card-icon` 色块
  4. `styles/index.scss`：新增 `--gp-accent-lightest: rgba(245,135,66,0.12)`（未提交卡图标块底）
- 关键经验：区块卡片化（surface 底）后，所有原以 surface 为对比底色的元素（表格行 hover、覆盖率轨道、chips 底）会隐形，需换成 theme-background 或语义 lightest 色
- 修正：用户反馈总览卡不需要图标，已回退为「数值+标签」双段式（数值保留语义色修饰，stat-card mixin 合流与网格/卡片化布局保留），--gp-accent-lightest 变量已回收
