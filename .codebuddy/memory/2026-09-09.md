### 经验
- 用户跑 vite build 报 4 个 MISSING_EXPORT 后补完 import 切换——**重构多文件 import 来源时应在同一轮内全量切完再交付**，不能改一半。
- `stream.pipeline` vs `.pipe`：源流 error 时 pipe 不销毁 dest，Windows 上 unlink 打开的文件必 EPERM——失败清理必须先 destroy 或用 pipeline。
- 非 deep watch 对「原地 splice/unshift 的同一数组引用」永不触发，props 数组清理逻辑必须 deep。
