### 设计要点与经验

- **数据驱动渲染**：动态 `<component :is="group.component" v-bind="example.props">` + `slotText` 作默认插槽；`code` 字段与 props 同源手工维护。props 为 `Record<string, any>`，无编译期约束，需人工保证图标键为已注册 IconKey、v-model 组件用 `modelValue`。
- **Select/Input/Slider 组件会从 attrs 剥离 class/style**（`containerAttrs` 解构丢弃），因此**不能靠 props 传 style 控宽**，改由预览 SCSS 容器控制。
- **Loader 组件 height:100%** 依赖父容器显式高度，需单独给 stage `height: 160px`（`cp-card__stage--loader`）才能显示。
- **快捷键冲突检查方法**：`Select-String -Path src\features\*\index.ts -Pattern 'hotkey:'` 汇总已占用键位（本项目 ⌃⌥B/C/D/E/I/N/O/R/T/W 已用），⌃⌥V 空闲。
- **尺寸级固定像素**（图标按钮 22/24px、侧栏 180px、搜索框 200px）项目既有约定允许，但建议加 `// 无对应 Token` 注释对齐既有 18 处写法。
- 架构校验：`universal-arch-skill` 的 `validate-project-structure.py --lang vue --features componentPreview` 输出 **0 错误 0 警告**；read_lints 全模块 0 错误；无跨 feature 直接导入、无绕过统一入口调用。

## 追加：预览卡片尺寸档位（用户需求「可以设置可选大小吗」→ 选定「预览卡片尺寸档位」）

用户四选项（卡片档位/浮动窗口尺寸/组件 size 切换/整体缩放）中只选了**预览卡片尺寸档位**（紧凑/舒适/宽松）。

### 实现
- **档位定义**：新增 `types/density.ts`（`PreviewDensity` 类型 + `DensityOption` + `PREVIEW_DENSITIES` 清单 + `DEFAULT_PREVIEW_DENSITY` + `isPreviewDensity` 守卫）。**关键：拆独立文件而非放 types/index.ts** —— 因 `types/index.ts` 运行时 import `../index.vue`（PreviewManager 挂载面板），若 composable 再从 types/index.ts 运行时导入常量会形成 `index.vue → composable → types/index.ts → index.vue` 运行时循环，有 TDZ 风险；`types/index.ts` 用 `export ... from "./density"` 转出保持对外入口不变。
- **持久化**：新增 `composables/usePreviewDensity.ts`（39 行），`PluginStorage` + `TypedStorage<PreviewDensity>`（key `component-preview-density`）+ `isPreviewDensity` 兜底损坏值；面板 `onMounted` 加载、`setDensity` 切换即落盘（不 await）。
- **UI**：头部 actions 内新增 `.cp-density` 分段切换器（S/M/L 短标签 + i18n tooltip，参照 codex-ui-reference 的 tabs 样式：surface 底 + active 用 background 凸出 + border）。
- **样式联动**：用 CSS 变量做单一数据源 —— `.cp-panel` 定义 `--cp-grid-min/--cp-stage-min-h/--cp-stage-pad/--cp-loader-h`（默认=舒适档），`.cp-panel--compact` / `.cp-panel--spacious` 覆盖（写在 `.cp-panel` 之后，同优先级后者胜）；`PreviewSection.scss` 的网格列宽、舞台高度/内边距、Loader 高度全部改为消费变量，避免三份重复规则。
  - 数值：紧凑 170px/72px/$spacing-2/120px；舒适 230px/96px/$spacing-4/160px；宽松 320px/140px/$spacing-5/220px。
- **i18n**：zh/en 各 +3 键（densityCompact/densityComfortable/densitySpacious），`I18n` 接口同步；键总数 19 对齐。

## 更正：「大小设置」是组件尺寸，不是卡片尺寸（推翻上一条卡片档位实现）

用户澄清原话：「大小设置是组件的尺寸，不是卡片的」。此前我在四选一中理解偏了（做了卡片/网格尺寸档位），实际需求是**组件自身 `size` prop 的档位切换**。

**重构内容（替换而非叠加）**：
- 删除 `types/density.ts` + `composables/usePreviewDensity.ts`（卡片档位）
- 新建 `types/size.ts`：`ComponentSize = "xsmall" | "small" | "medium" | "large"`、`SizeOption`、`COMPONENT_SIZES`、`DEFAULT_COMPONENT_SIZE = "small"`、`isComponentSize`
- 新建 `composables/usePreviewSize.ts`：storage key `component-preview-size`（旧 key 作废）
- `PreviewGroup` 新增 `sizeable?: boolean`；11 个支持 size 的组件标记为 true（Button/Input/FormField/Label/Select/Switch/Slider/Tag/Badge/Avatar/Card）；**Chart（size 为预设像素宽高，大档撑破卡片）/ IconWrapper（size 为像素数）/ Loader（无 props）不参与**
- `PreviewSection.vue` 新增 `size` prop + `resolveProps(example)`：`sizeable` 且示例**未显式指定 size** 时注入全局档位；显式指定 size 的示例（尺寸对比用例）保持原样，避免标题与实际渲染不符
- 回退卡片布局：`.cp-panel` 的 4 个档位 CSS 变量与 `.cp-panel--compact/spacious` 全部移除，网格列宽回 `minmax(230px,1fr)`、舞台回 96px/Loader 160px；切换器类名 `.cp-density*` → `.cp-size*`
- i18n：`densityCompact/Comfortable/Spacious` → `sizeXsmall/sizeSmall/sizeMedium/sizeLarge`（zh/en 20 键对齐）

验证：density 残留 grep 0；sizeable 标记 11 处；i18n 20 键对齐；read_lints 0；结构校验 0/0；行数最大 279。

**经验**：需求澄清阶段我给的选项描述里「组件 size 参数切换」与「预览卡片尺寸档位」区分度不够，导致用户误选；涉及"大小/尺寸"类需求时，应先用一句话确认是**被预览组件自身的尺寸**还是**预览界面/容器的尺寸**。
