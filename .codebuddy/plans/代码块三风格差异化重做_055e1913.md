## 产品概述

重做代码块美化主题的三种预设风格（GitHub / Mac / Default），解决当前三者视觉差异过小的问题，使每种风格一眼可辨。

## 核心功能

- **GitHub 风格微调**：语言标签从居中改为左对齐、圆角从 8px 收窄至 6px，更贴近真实 GitHub 代码块外观，同时保留思源主题色变量适配。
- **Mac 风格重做**：顶部工具栏改为深色标题栏（macOS 终端特征色），语言标签与操作图标反色为浅色，三色点保持原有红黄绿，形成与其他风格的鲜明区分。
- **Default 风格保持原生**：维持现有"接近原生、hover 显边框"的表现，不改动。
- **描述文案同步**：更新 Mac 风格描述文案，使设置面板中的文字与实际视觉一致。

## 技术栈

- 样式层：SCSS（复用项目现有 `_variables.scss` 设计 Token 与思源 `--b3-theme-*` 主题变量）
- 改动范围：纯 CSS 视觉调整，不涉及 Vue 组件逻辑、存储或 i18n 合并产物（合并 JSON 由脚本生成）

## 实现方案

### 核心思路

通过差异化三种风格的「标题栏」视觉语言来拉大区分度：GitHub 走"浅色标题栏 + 语言靠左 + 6px 圆角"的克制路线；Mac 走"深色标题栏 + 三色点 + 12px 圆角"的终端窗口路线；Default 保持无标题栏的原生路线。三者标题栏颜色（浅色/深色/无）形成最大差异点。

### GitHub 风格微调（保留主题适配）

1. **语言标签左对齐**：在 `body.codeblock-style-github` 块内覆盖通用块的居中定位，改为 `left: $spacing-2; margin-left: 0`。复制按钮已由通用块的 `.protyle-icon { margin-left: auto }` 靠右，无需改动，天然形成"语言居左、操作居右"的真实 GitHub header 布局。
2. **圆角收窄至 6px**：将 `_variables.scss` 中 `$codeblock-border-radius: 8px` 改为 `$codeblock-border-radius: $radius-base`（`$radius-base` 即 6px），消除硬编码重复的同时让 GitHub 块自动获得 6px 圆角，GitHub 块自身选择器无需修改。
3. **保持不变**：背景 `var(--b3-theme-surface)`、边框 `var(--b3-theme-outline)`、header 浅色背景、行号右对齐浅灰均继续沿用，不新增硬编码色。

### Mac 风格重做（深色标题栏）

1. **标题栏深色背景**：`body.codeblock-style-mac` 块内 `.protyle-action` 的背景从浅色 `rgba(..., 0.04)` 改为固定深色 `#1f1f1f`（macOS 终端/iTerm 特征色），与三色点同为"固定品牌色 + 注释"例外处理。
2. **文字反色**：`.protyle-action__language` 与 `.protyle-icon` 的颜色从 `var(--b3-theme-on-surface-variant)` 改为浅色 `rgba(255, 255, 255, 0.85)`，保证深色标题栏上的对比度。
3. **布局保持**：三色点 `&::before` 已为 flex 首项靠左，语言标签保持居中（真实 macOS 窗口标题居中），圆角保持 `$radius-lg`(12px)，与 GitHub 的 6px 形成差异。
4. **标题栏分隔线**：`border-bottom: 1px solid var(--b3-theme-outline)` 在深色背景上不协调，可移除或改为半透明白色。

### Default 风格

不修改，已符合"接近原生"定位。

## 实现要点

- **品牌色例外注释**：Mac 深色标题栏 `#1f1f1f` 与浅色文字 `rgba(255,255,255,0.85)` 必须在注释中说明为"macOS 终端标题栏固定色"，与现有三色点注释模式一致；其余色值/圆角/间距一律使用 Token。
- **行数控制**：当前文件 193 行，本次改动后必须低于 300 行硬阈值。
- **验证边界**：AI 不执行 `pnpm build`、`pnpm lint`、`pnpm i18n:merge`，由用户自行验证；AI 仅做 `read_lints` 与全项目搜索确认无死变量/无遗漏引用。
