## 产品概述

优化思源笔记插件代码块折叠的视觉效果：移除折叠处底部的模糊渐变阴影遮罩，使折叠边界清晰、简洁、大方。

## 核心功能

- 删除代码块折叠时底部的渐变模糊遮罩（`.code-collapse-fade` 元素及其样式）
- 保留底部「展开/收起」按钮栏及其 `border-top` 上边框分隔线
- 折叠效果简化为 `maxHeight` 截断 + 清晰边框分隔，无模糊阴影过渡

## 技术栈

- TypeScript（模板字符串注入 CSS 与 JS）
- 原生 DOM 操作（`document.createElement` / `appendChild`）

## 实现方案

仅修改 `src/features/generalSettings/utils/styles.ts` 的 `applyCodeBlockCollapse` 函数，删除模糊渐变遮罩的两处相关代码：

1. **删除 CSS 规则**（第 243~256 行）：移除 `.code-block.code-block-collapse-wrapper .code-collapse-fade` 与 `.code-block.code-block-collapse-wrapper:not(.code-block-collapsed) .code-collapse-fade` 两段规则（渐变背景 `linear-gradient(to bottom, transparent, var(--b3-theme-surface))` 即为模糊阴影来源）
2. **删除 JS 创建逻辑**（第 348~351 行）：移除 `const fade = document.createElement('div')` 至 `codeBlock.appendChild(fade)` 共 4 行

## 实现注意事项

- **改动边界**：保留 `.code-collapse-bar`（第 258~267 行，自带 `border-top: 1px solid var(--b3-border-color)` 提供清晰分隔线）、`.code-collapse-btn`、`.code-collapse-line-info` 及折叠展开/收起逻辑不变
- **保守保留** `.code-block.code-block-collapse-wrapper { position: relative; }`（第 234~236 行）：原为 absolute 定位的 fade 提供包含块，删除后相对定位不影响 sticky 子元素，为避免扩大改动范围保守不动
- **引用安全**：已全局搜索确认 `code-collapse-fade` 类名仅在 `styles.ts` 中出现（3 处：2 处 CSS 规则 + 1 处 JS className），删除无副作用
- 不新增样式、不改 i18n、不改图标注册
- 遵循项目规则：AI 不执行 `pnpm lint` / `pnpm vite build`，改完由用户自行验证
