## 用户需求

对项目全部 `.scss` 文件执行字体规范全量修复，将硬编码的字体三要素替换为标准设计 Token，严格执行 Codex 两级字号制。

## 修复范围（用户已确认）

1. **全量修复**：覆盖所有违规 .scss 文件（约 90 个），一次到位
2. **中间字号收敛**：9px→10px、11px→10/12px、13px→12px、15px→14px，统一到两级字号制
3. **行高**：本次仅替换 1.5（→`$line-height-normal`），其余无 Token 行高（1/1.3/1.4/1.6/1.7/px 值）保留硬编码
4. **vue 内联样式**：不纳入，仅处理 .scss 文件

## 核心规则

- `font-size` / `font-weight` / `line-height` 禁止硬编码 px/数字值，必须使用 `$font-size-*` / `$font-weight-*` / `$line-height-*` Token
- 两级字号制：标题与正文 `$font-size-xs`(12px)，辅助文字 `$font-size-2xs`(10px)；`$font-size-sm`(14px) 及以上仅限阅读区正文与数据突出展示，且须加注释说明用途

## 技术栈

- SCSS + 项目现有设计 Token 体系（`src/_variables.scss`，Token 已完整定义，无需新增）
- 纯样式替换，无运行时性能影响，不引入新依赖
- 所有目标模块已通过 `@use '@/variables.scss' as *` 导入变量

## 实现方法

采用**按替换类型分组**的策略：同类替换规则统一，可批量搜索替换，减少上下文切换。共 5 类替换任务（font-weight 全量、font-size 标准值、font-size 中间字号收敛、components 注释清理、line-height 1.5）。

## 实现注意

- **机械替换保格式**：替换时保持原缩进与选择器结构不变，仅替换值部分
- **14px 判断标准**：位于 Markdown 预览、统计数值、大标题等阅读/数据突出场景→替换 `$font-size-sm` 并追加注释（如 `// 数据突出展示`）；位于标签/提示/列表正文等→降级 `$font-size-xs`
- **11px 判断标准**：辅助文字（标签、提示、状态、元信息）→`$font-size-2xs`；正文内容→`$font-size-xs`
- **避免误伤**：跳过例外清单中的行、第三方库覆盖行、以及 `$codeblock-font-size` 定义行
- **验证**：修改完成后由用户自行执行 `pnpm lint` 与 `npx tsc --noEmit`（AI 不执行 lint/build）
