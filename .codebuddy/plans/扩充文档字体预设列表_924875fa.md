## 需求概述

用户参考思源美化仓库 langzhou/siyuan-note 及其 Toy 主题，希望把其中字体加入「文档字体设置」的预设下拉列表（DocumentFontSettings.vue 的 `PRESET_FONTS` 数组）。

## 调研结论

经抓取该仓库 README、Toy 主题的 theme.css（仅含 @import）与 base.css，均未发现具体的 font-family 配置，主题依赖思源内置字体。因此采用合理假设，加入思源美化社区通用的开源/免费中文字体预设。

## 核心功能

- 在「文档字体设置」的预设字体下拉列表中追加约 10 个思源美化社区常用开源中文字体。
- 保持现有 `PRESET_FONTS` 条目结构与 `value`/`label` 格式，不改动原有 11 条。
- 纯展示性数据追加，不涉及存储结构、样式注入逻辑、注册清单或 i18n。

## 技术方案

### 改动范围（单点、单文件）

文件：`src/features/generalSettings/components/DocumentFontSettings.vue`
位置：`PRESET_FONTS: SelectOption[]` 常量（约第 257-269 行）

### 新增字体条目

遵循现有 `{ value, label }` 格式（value 为真实 font-family 名，label 为展示名；字体名为专有名词不走 i18n）：

| value | label |
| --- | --- |
| Source Han Serif SC | 思源宋体 |
| Source Han Serif CN | 思源宋体 (CN) |
| Source Han Sans SC | 思源黑体 |
| Source Han Sans CN | 思源黑体 (CN) |
| LXGW WenKai | 霞鹜文楷 (LXGW WenKai) |
| PingFang SC | 苹方 (PingFang SC) |
| HarmonyOS Sans SC | HarmonyOS Sans |
| Sarasa Gothic SC | 更纱黑体 (Sarasa Gothic) |
| 仓耳今楷01 W03 | 仓耳今楷 |
| ZCOOL XiaoWei | 站酷小薇 (ZCOOL XiaoWei) |


### 执行要点

- 仅追加，不改动现有 11 条条目。
- 思源字体提供 SC/CN 双变体以兼容不同系统/平台的安装版本。
- 不需 i18n：沿用现有"字体名为专有名词，label 保留原生名称"约定。
- 不需改动 `applyDocumentFontStyles`（styles.ts 已支持多字体逗号分隔字符串），`previewStyle` 直接消费 `fontFamily` 字符串，自动生效。
- 无新依赖、无存储结构变更、无图标/SCSS/注册清单改动。

### 验证

- AI 不执行 `pnpm lint` / `pnpm vite build`，由用户自行运行 4 项验证（lint / i18n:verify / validate:icons / tsc）。
