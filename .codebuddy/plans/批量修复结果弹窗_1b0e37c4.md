## 产品概述

为 gitPush 违规批量修复增加**结果对照弹窗**：点击「批量修复」执行完成后，自动弹出窗口展示本次处理的每个提交的明细。已修复项展示「原提交信息 → 修复后信息」的 before/after 对照，已跳过项展示跳过原因，失败项展示失败状态，让用户清楚看到批量修复到底改了什么、哪些没改、为什么没改。

## 核心功能

1. **逐项结果数据**：批量修复执行时收集每个选中项的明细（项目名、hash、违规原因、原提交信息、修复后信息、状态）
2. **结果对照弹窗**：点击批量修复后弹出，按状态分区块展示——已修复（绿色对照）、已跳过（黄色原因）、失败（红色）
3. **交互细节**：支持 Esc / 点击遮罩关闭；修复完成且存在成功项时仍触发列表刷新，弹窗与刷新并行不冲突

## 技术栈

沿用现有 Vue 3 + TypeScript 组合式 API，参考项目既有弹窗模式（`LogDetailDialog.vue`），不引入新依赖。

## 实现方案

### 1. 数据扩展（`composables/useBatchCommitFix.ts`）

- 新增类型：`BatchFixItemStatus = "fixed" | "skipped" | "failed"`、`BatchFixItem { projectId, projectName, hash, reason, original, fixed?, status }`
- `BatchFixResult` 新增 `items: BatchFixItem[]`
- `fixSelected()` 循环内顺带收集：可修复并改写成功 → `{ status: "fixed", original, fixed }`；不可修复 → `{ status: "skipped", reason }`；项目缺失/改写失败 → `{ status: "failed" }`
- 初始 result 含 `items: []`（未勾选/无目标的提前返回路径不受影响）

### 2. 结果弹窗组件（新增 `components/CommitRuleCheck/BatchFixResultDialog.vue`）

参考 `LogDetailDialog.vue` 结构：

- `Teleport to="body"` + `Transition name="gp-dialog-fade"` + 根节点 `tabindex="-1"` + `@keydown.escape` / `@click.self` 关闭
- `useDialogKeyboard(computed(() => !!props.result))` 聚焦根节点
- props：`result: BatchFixResult | null` + `i18n`；emit：`close`
- body 分三区块（仅渲染非空区块）：
- **已修复**（绿色）：每项展示项目名 + hash 短码 + 原信息（删除线）+ 修复后信息（绿色）
- **已跳过**（黄色）：项目名 + hash + 违规原因标签（复用 `COMMIT_RULE_REASON_META[reason].labelKey`）
- **失败**（红色）：项目名 + hash
- footer：关闭按钮（`vp-btn`）

### 3. 触发接入（`components/CommitRuleCheck/ViolationListSection.vue`）

- 新增 `resultDialog = ref<BatchFixResult | null>(null)`
- `runBatchFix()` 完成后：`if (result.items.length > 0) resultDialog.value = result`（未勾选/无目标时 items 为空，不弹窗，保持既有引导提示）
- 模板尾部挂载 `<BatchFixResultDialog :result="resultDialog" :i18n="i18n" @close="resultDialog = null" />`
- `emit("batchFixed")` 刷新逻辑不变（弹窗数据是快照，刷新后仍可查看）

### 4. i18n 与样式

- `src/i18n/{zh_CN,en_US}/gitPush.json` 新增键：`batchFixResultTitle`（批量修复结果）、`batchFixResultFixed`（已修复）、`batchFixResultSkipped`（已跳过）、`batchFixResultFailed`（失败）、`batchFixResultOriginal`（原信息）、`batchFixResultFixedLabel`（修复后）
- 新增 `styles/BatchFixResultDialog.scss`（`gp-bfr-*` 前缀）：overlay/dialog/header/body 分区块/对照行样式；对照用删除线 + 绿色新文案；状态色用 `var(--b3-theme-success/warning/error)` 语义色 + 设计 Token

## 设计风格

遵循项目 Codex UI 风格：采用项目统一的 overlay 弹窗模式（半透明遮罩 + 边框卡片对话框），弹窗内容按状态分区，信息层级清晰。

- **已修复区**：主色/绿色强调，每项以「原信息（删除线、弱化）→ 修复后信息（绿色）」对照呈现，用户一眼看出改动
- **已跳过区**：警告色原因标签（复用违规类型 i18n 文案，如"缺少 type"），弱化显示
- **失败区**：错误色，明确区分
- 标题栏：标题 + 统计徽章（成功/跳过/失败计数）+ 关闭按钮；底部单一「关闭」主操作
- 弹窗尺寸紧凑（约 480px 宽），内容超长可滚动，滚动内容与边缘保持间距
