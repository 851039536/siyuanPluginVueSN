## 用户需求

移除统计模块「笔记分布」Tab 中「各笔记本块类型分布」统计图表，并对其余 UI 布局进行重构优化，使移除后不留下空白区块。

## 核心功能

- 删除「各笔记本块类型分布」堆叠图卡片（NotebookBlockTypeChart）及其数据加载链路
- 将原 4 行 CSS Grid 布局精简为 3 行：汇总摘要栏（全宽）→ 文档数柱状图 + 字数占比饼图（左右两列等高）→ 笔记本排行表格（全宽）
- 清理仅服务于该统计的查询函数、composable 状态、类型定义、i18n 键及组件/样式文件
- 保留概览 Tab 的「整体块类型分布」功能，不误删其共享常量与标签文案

## 技术栈

- Vue 3 + TypeScript（沿用现有统计模块架构）
- SCSS（沿用 Codex 设计 Token 与 SCSS 分离规范）

## 实现方案

### 总体策略

先移除 UI 层对堆叠图组件的引用并重排网格，再自外向内清理数据加载层、类型层、组件/样式文件与 i18n，避免出现悬空引用或编译断裂。

### 关键决策

- **布局重构**：删除 `.dist-right-stack` 规则后，原右列第 3 行出现空档。将 `.notebook-distribution-tab` 的 `grid-template-rows` 由 `auto auto auto auto` 改为 `auto auto auto`；`.dist-left` 由 `grid-row: 2 / 4` 改为 `grid-row: 2`；`.dist-table` 由 `grid-row: 4` 改为 `grid-row: 3`。文档柱状图与字数饼图在 row2 通过 `align-items: stretch` 等高对齐，柱状图 `flex: 1` 填满卡片，饼图内容垂直居中。
- **最小高度平衡**：为 `.dist-left`、`.dist-right-pie` 增加与 `.dist-table` 一致的 `min-height: 200px`，避免笔记本数量少时两列卡片过矮、布局失衡。
- **保留共享资产**：`BLOCK_TYPE_LABELS` 常量及 `blockTypeD`…`blockTypeTag` i18n 键仍被 `queries/baseStats.ts` 的「整体块类型分布」使用，必须保留。
- **i18n 只改分片**：仅修改 `src/i18n/zh_CN/statistics.json` 与 `src/i18n/en_US/statistics.json`，禁止手动修改顶层合并 JSON（构建时由 `pnpm i18n:merge` 自动重新生成）。

## 实施注意

- 顺序上先改 `index.vue` 再删除组件文件，防止出现 import 悬空。
- 删除 `getNotebookBlockTypeStats` 时同步移除 `notebookStats.ts` 顶部已不再使用的 `BLOCK_TYPE_LABELS`、`NotebookBlockTypeRow`、`NotebookBlockTypeStat` 导入，避免 lint 报未使用。
- 本次为纯删除与布局精简，不引入新依赖、新组件模式；验证交由用户执行 `pnpm lint`、`pnpm i18n:verify`、`npx tsc --noEmit`。
