## 模型下拉"双层框"修复（同日）
- 根因：`.setting-select` 类落在共享 Select 组件根容器（.si-select）上，而样式仍带原生 `<select>` 时代的完整盒子（border/padding/background/SVG 箭头）——与组件内部 `.si-select__trigger` 自带视觉叠成双层边框+双箭头。原生 select 换自定义组件时的历史遗留，非样式迁移引入（迁移前全局规则同样命中）。
- 修复：AiSettingsPanel.scss 中 `.setting-select` 撤掉全部盒子样式，只留 `width: 100%`（对齐 profile-select 惯例）+ cursor；`.setting-input`（TextInput 原生 input）保留完整盒子。
- 经验：superPanel 的共享组件类名有两类语义——`.setting-input`=原生 input 要盒子；`.setting-select`=组件容器不要盒子。审查时迁移样式必须核对 class 落点元素。
