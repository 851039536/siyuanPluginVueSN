# toolCollection index.vue 布局优化与冗余删除

目标模块：`src/features/toolCollection/`（tools/ 子工具自身的内部 Tab UI 不动，它们是各自的功能）

## 一、index.vue 结构精简（277 行，模板去重 + 死代码清除）

1. **Resize 按钮 v-for 化**：头部 4 组变窄/宽/矮/高按钮是同构模板重复（L32–81，约 50 行）。改为本地 `RESIZE_ACTIONS` 配置数组 `{ dimension, delta, icon, titleKey }` + 单个 `v-for` 渲染，disabled 用提取的边界常量计算。
2. **边界魔数常量化**：`500/1600/30/100` 在模板、`usePanelResize.ts` L40–41、`useDragResize.ts` L23–24 三处漂移。按 AGENTS 分层规则提取到 `types/index.ts`：`PANEL_WIDTH_MIN/MAX = 500/1600`、`PANEL_HEIGHT_MIN/MAX = 30/100`，三处统一引用。
3. **maxHeight 数值矛盾修复**：SCSS `calc(88vh - 32px)` ↔ `panelStyle` 内联 `calc(88vh - 36px)`（内联实际生效）、注释写 `bottom: 36px` 实际是 32px。统一为一个数值，以 JS 内联为准对齐 SCSS 与注释。
4. **死代码删除**：
   - `PanelI18n` 接口的 `prevTool/nextTool` 死字段（L186–187，重构后无模板引用）
   - `header-float` 上恒真的 `v-if="!isFloating"`（L85，外层 header 已有同条件）
   - 根节点 v-if 表达式简化为 `mode === 'tab' || !!visible?.value`
5. **命名**：`activeTabRef` → `activeToolRef`。

## 二、视觉微调

1. **键盘提示补全**：侧栏底部 `"←→ ↑↓"` 与实际映射不符（缺 Home/End/Ctrl+1~9/Esc）。改为新 i18n 键 `toolCollectionPanel.keyhint`（zh: "↑↓ ←→ 切换 · Ctrl+数字跳转"；en 同步），补充中文 HTML 注释。
2. **图标按钮尺寸合规**：`resize-btn` 22px → 26px、`header-close/header-float` 24px → 26px、icon 12/14 → 16px（对齐 AGENTS_STYLE.md L98 强制标准）。
3. **尺寸标签带单位**：`resize-label` 显示裸数字 "1060"/"60" → 显示 "1060px"/"60vh"。
4. **SCSS Token 化**：`gap: 2px`、`margin: 0 2px` → `$spacing-2px`；4 处重复的 `cubic-bezier(0.4,0,0.2,1)` + 时长提为文件内变量；删 media query 中冗余的 `border-radius` 重申（L305）。
