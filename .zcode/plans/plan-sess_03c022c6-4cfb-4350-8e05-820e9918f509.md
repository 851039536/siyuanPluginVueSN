**合规面良好**：8 步注册链完整（含编译期断言）、统一入口零违规（剪贴板/Modal/存储/事件全走规范通道）、跨功能零直接导入、SCSS 全外置、i18n 分片 47 键 zh/en 对齐、无文件超 300 警戒线、README 合规、旧格式迁移走 TypedStorage。

**发现的问题**：

  1. 子组件数据流违规：`index.vue:115` 父维护 `editingPrompt` 全量中间 ref；`PromptFormModal.vue:269` emit 全量 Prompt、`CategoryManageModal.vue:96/118` emit 完整对象/删除——两弹窗未自包含（`DeleteConfirmModal` 是正确范式对照）
  2. 默认分类色 `#d97757` 在 3 文件 6 处硬编码（index.vue:183 / useCategoryManager.ts:33,39,55 / CategoryManageModal.vue:102,114），未提取共享常量
  3. 4 个 .ts 文件缺文件头注释（index.ts、usePrompts.ts、useCategoryManager.ts、types/storage.ts）
- **中**：`usePrompts.ts:34-39` 迁移判定与 `storage.ts:50-93` 双写；`_mixins.scss:56` box-shadow（明令禁止）、`:17` rgba 遮罩硬编码；`768px` 断点 4 文件 5 处未用 `$mobile-breakpoint`；i18n 渲染点无中文标注注释、aria-label 硬编码中文 5 处；`index.ts` 惰性 Modal 单例永不销毁（未入 DESTROYABLE_KEYS，插件重载泄漏）；`CategorySidebar.vue` 缺第二行 index.scss 导入；父模板监听 kebab-case 7 处
- **仅记录不改**：项目级 `_mixins.scss` modal 样式在 10+ 功能近似复制（建议日后建共享基座）；入口图标不一致（悬浮框 mdi:star vs FEATURE_ICONS mdi:brain，属视觉取舍）；零散 px 尺寸；PromptsGrid 列表中继事件（列表视图可接受）

## 修复步骤

### A. 弹窗自包含重构（数据流合规）
- **PromptFormModal.vue**：props 改为 `show` + `editingId: string | null`（最小标识符）+ `promptManager` + `categoryManager`（manager 实例）+ `i18n`；打开时自行按 id 从 manager 查 Prompt 初始化表单；保存时直接调 `promptManager.add/update`，仅 emit `close`（无数据载荷）；校验与 showMessage 逻辑保留
- **CategoryManageModal.vue**：props 改为 `show` + `categoryManager` + `promptManager` + `i18n`；新增分类直接调 `categoryManager.add`（id 生成留在子组件）；删除前自行用 `promptManager.prompts` 做"分类非空"校验，通过后直接调 `categoryManager.remove`；仅 emit `close`
- **index.vue**：`editingPrompt` 全量 ref 改为 `editingId: string | null`；删除 `handleSave`/`addCategory`/`handleCategoryDelete` 中间人；新增 watch：`selectedCategory` 不在分类列表时重置为 `"all"`（替代原删除回调里的对账）；PromptsGrid 列表中继保持不动（父取 `p.id`）

### B. 共享常量提取
- `types/index.ts` 新增 `DEFAULT_CATEGORY_COLOR = "#d97757"`；6 处硬编码全部改引（`bg` 用 `${DEFAULT_CATEGORY_COLOR}20` 派生）

### C. 迁移判定收敛
- `usePrompts.ts` 的 `needMigration` 判定移入 `PromptsStorage`（与 `migratePrompts` 的跳过条件单源化），迁移编排整体下沉 Storage：`loadPromptsWithMigration()` 内完成旧格式迁移 + 回写，`usePrompts.load()` 退化为纯加载

### D. 文件头注释
- `index.ts`、`composables/usePrompts.ts`、`composables/useCategoryManager.ts`、`types/storage.ts`、`types/index.ts` 补文件级说明

### E. 样式 Token 违规
- `_mixins.scss:56` box-shadow 焦点环改 `outline: 2px solid var(--b3-theme-primary-lightest)` + `outline-offset: -2px`（避免布局位移）；`:17` 遮罩色提为文件内局部变量 `$modal-overlay-bg`；4 个 scss 的 `768px` ×5 改 `$mobile-breakpoint`
- `CategorySidebar.vue` style 块补 `@use '../styles/index.scss';` 第二行导入

### F. i18n 合规
- 全部 i18n 渲染点补 `<!-- xx："中文" -->` 标注（index.vue / PromptsGrid / PromptFormModal / CategoryManageModal / CategorySidebar / DeleteConfirmModal，模板区块注释已有）
- aria-label 硬编码中文 5 处改走 i18n：能复用现有键的复用（如"分类名称"已有 `categoryName`），缺键的在 `prompts.json` zh/en 同步补（约 3 个新键）

### G. Modal 单例销毁（实例挂载模式）
- `index.ts`：首次创建 Modal 时自挂载 `(plugin as any).__promptsModal = { destroy: () => { modal?.destroy(); modal = null } }`；`src/index.ts` 的 `DESTROYABLE_KEYS` 增加 `"__promptsModal"`，onunload 统一销毁

### H. 事件命名
- `index.vue` 模板监听 7 处 kebab-case（`@select-category` 等）改 camelCase（`@selectCategory`）
