## 目标

为 flashcardReading 增加"标记单词"能力：被标记的词默认不再出现在"边学边写"练习队列中；边学边写顶部提供总开关（默认关闭，即不过滤），持久化到 `TypingSettings`。标记入口两处：列表卡片按钮 + 边学边写页面内当前词按钮。

## 改动清单（8 个文件）

### 1. 数据模型 `src/utils/sharedStorage/flashcardStorage.ts`
- `Flashcard` 接口加 `typingHidden?: boolean`
- `UpdateFlashcardDTO` 加 `typingHidden?: boolean`（`updateCard` 展开合并自动支持切换）
- `getAllCards()` 归一化处补 `typingHidden: card.typingHidden ?? false`（沿用 `practiceCount` 迁移范式）
- `TypingSettings` 加 `hideMarked: boolean`，`DEFAULT_SETTINGS` 加 `hideMarked: false`

### 2. i18n 三处同步
- `src/features/flashcardReading/types/index.ts` 的 `I18n` 接口 + `composables/useI18n.ts` 的 `DEFAULT_I18N` 加键：
  - `typingHideMarkedOn`（"隐藏标记"/"Hide Marked"）、`typingHideMarkedOff`（"显示标记"/"Show Marked"）
  - `typingTitleHideMarkedOn`/`Off`（title 提示："当前：边学边写隐藏已标记单词"等）
  - `markForTypingHide`（"标记后边学边写不显示"）、`unmarkForTypingHide`（"已标记：边学边写中隐藏，点击恢复"）
- `src/i18n/zh_CN/flashcardReading.json` + `en_US/flashcardReading.json` 同步添加（不直接改合并产物）

### 3. 列表标记按钮 `components/CardList.vue`
- `card-actions` 中新增 ghost 按钮（play 前）：图标反映该词在边学边写中的当前可见性——未标记 `eye`（title=`t.markForTypingHide`），已标记 `eyeOff`（title=`t.unmarkForTypingHide`）
- 新 emit `toggleTypingHidden: [card: Flashcard]`
- 已标记卡片的标题加弱化样式 class（新样式加到 `styles/index.scss` 的 card-header 区域，用 `$color-*` token）

### 4. 边学边写组件 `components/TypingPractice.vue`
- 顶部 `typing-controls__options` 新增第 5 个 toggle（复用 `typing-case-toggle` 样式，零新样式）：active 显示 `eyeOff` + `t.typingHideMarkedOn`，inactive `eye` + `t.typingHideMarkedOff`；新 prop `hideMarked` + emit `update:hideMarked`
- `typing-reference__footer`（播放按钮旁）新增标记按钮：未标记 `eyeOff`、已标记 `eye`，emit `toggleHidden: [card]`

### 5. 主面板接线 `index.vue`
- `hideMarked` ref + 持久化：加入 `saveTypingSettings()` 与 `onMounted` 读取；`onHideMarkedToggle` 中切换后 `typingQueue.rebuild()` + 归零索引
- 新 computed `typingCards`（`hideMarked` 开启时从 `filteredCards` 滤掉 `typingHidden`），`useTypingQueue(typingCards)`；模板 typing 视图的空态判断（L43）从 `filteredCards.length` 改为 `typingCards.length`
- `toggleTypingHidden(card)`：`storage.updateCard(card.id, { typingHidden: !card.typingHidden })` → `emitCustomEvent("flashcardDataChanged")`（走 `@/utils/eventBus`，与 CardDialog 一致）→ `reload()`；若处于 typing 视图且 `hideMarked` 开启，直接从 `typingQueue.queue.value` 中移除该卡（不打断练习节奏，索引越界归 0），列表视图无需特殊处理
- 模板接线：CardList 加 `@toggleTypingHidden`，TypingPractice 加 prop/emit

### 6. 文档 `src/features/flashcardReading/README.md`
- 补充标记过滤功能说明
