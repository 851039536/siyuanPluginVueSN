仅修复 prompts 模块的代码逻辑漏洞（不修改 apiDebugger 与 diskBrowser）：

1. `usePrompts.ts`：
   - `load()` 增加 try/catch，加载失败时置空列表并输出错误，避免 `loading` 永远为 true。
   - `add/update/remove` 增加 storage 非空守卫，避免静默失败。

2. `useCategoryManager.ts`：
   - `load()` 增加 try/catch，失败时保留默认分类，避免未处理 rejection。

3. `index.vue`：
   - `onMounted` 初始化增加 try/catch，加载失败时提示错误并关闭 loading，避免未处理 rejection。

4. `PromptFormModal.vue`：
   - `watch(() => props.show, ...)` 补 `{ immediate: true }`，避免父组件初始 `show=true` 时表单空白。

验证：
- `npx eslint src/features/prompts --ext .ts,.vue,.scss`
- `npx vue-tsc --noEmit` 过滤 prompts
- `npm run i18n:verify`
