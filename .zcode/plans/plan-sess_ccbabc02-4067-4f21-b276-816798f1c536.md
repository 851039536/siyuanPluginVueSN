# 重构技术债务分区：文件与描述合并为整体块 + 冗余清理

## 现状问题（已确认）

1. **文件与描述不在一块**：`TechDebtSection.vue` 模板先 `v-for` 输出全部文件指标行（45-73 行），再 `v-for` 输出全部说明行（75-81 行）——说明与对应文件在 DOM 和视觉上完全分离。
2. **冗余 `groupRows(sev)`**：模板中调用 3 次（文件行 v-for、说明行 v-for、分组计数），每次都全量 `filter` 一遍 `debtFiles`。
3. **死类**：`.gpr-row--debt` 只剩 hover 高亮（行无点击行为）；`.gpr-cell--file` 的 `cursor: pointer` 同样无点击目标。

## 重构方案

### 1. 组件结构（`TechDebtSection.vue`）
每组改为「表头 + 文件块列表」——每个文件渲染为一个 `.gpr-debt-file` 块，块内指标行下方**紧跟**说明行：

```html
<div v-for="row in g.rows" :key="row.path" class="gpr-debt-file">
  <div class="gpr-row">            <!-- 指标行：路径/类型/评分/修改次数/复杂度/代码行数/稳定性 -->
    ...
  </div>
  <div v-if="row.description" class="gpr-row gpr-row--desc">
    <span class="gpr-cell gpr-cell--desc">{{ row.description }}</span>
  </div>
</div>
```

（`v-if="row.description"` 防空说明行破坏块视觉）

### 2. 分组预计算（消除 3 次 filter）
`groups` computed 单次 map+filter 产出严重/高/中三组，模板只遍历一次：

```ts
const groups = computed(() =>
  DEBT_SEVERITY_ORDER.map((sev) => ({
    sev,
    rows: props.report.debtFiles.filter((r) => r.severity === sev),
  })),
)
```

删除 `groupRows` 函数；组计数改用 `g.rows.length`。

### 3. 样式（`TechDebtSection.scss` + 共享基座）
- **新增 `.gpr-debt-file`**（块容器）：
  - `@include row-divider` 分隔不同文件块
  - `:hover` 整块高亮 `var(--b3-theme-surface)`（扫描辅助）
  - `.gpr-row { border-bottom: none }`——块内行关闭各自分割线，文件间区隔由块统一承担
- **`.gpr-row--desc`**：保持 `padding-top: 0` 紧贴指标行，新增浅色底 `background: var(--b3-list-hover)` 强化「文件+说明」配对视觉
- **清理死类**（`styles/index.scss`）：
  - 删除 `.gpr-row` 的 `&--debt { &:hover {...} }` 块（模板不再使用）
  - `.gpr-cell--file` 移除 `cursor: pointer`（无点击行为）

- `npx tsc --noEmit`：gitPush/report 范围 0 错误
