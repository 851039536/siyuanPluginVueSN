# 文档分析

分析思源笔记中的文档内容，帮助用户找到小文档/废弃文档，支持多平台发布。以右侧边栏 Dock 面板呈现。

## 主要功能

- **统计分析**：按字数、更新时间、深度、书签等维度统计文档分布；书签分布完全动态化（GROUP BY 全量统计实际存在的书签值，不预设任何固定书签）；发布状态分区汇总「完整/部分/未发布」并追加各平台已发布文档分布（可点击下钻）
- **健康度配置**：点击健康度信息图标查看扣分项明细，可勾选参与扣分分析的项（0B空/重名超出/无书签/部分发布/深度>7/字数>2万/孤文档/无标签/未发布），健康度百分比实时重算并持久化
- **多平台发布**：支持 GitHub、Halo、WordPress、Cnblogs 等多种平台
- **书签管理**：通过书签标记文档状态（如待发布/已发布/分类标签等，任意书签值均纳入动态统计）
- **完整发布判定**：在「平台管理」弹窗中可逐平台勾选「参与完整发布判定」，未勾选的平台不计入完整/部分/未发布统计（发布数量分布仍按全部平台统计）；全部关闭时回退为按全部平台判定
- **筛选排序**：支持标题/全文搜索、字数范围、多字段排序
- **批量操作**：批量标记、批量发布当前筛选结果

## 书签发布标准

| 书签 | 含义 |
|------|------|
| 待发布 | 调整好的文章，等待发布 |
| 已发布 | 发布完成后重新设书签分类，如：已发布→C# |
| 无 | 无需操作 |
| 其他（JS、C#、API 等） | 已发布并完成分类处理 |
