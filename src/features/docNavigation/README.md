# 文档导航

在文档编辑区顶部/底部显示父子文档导航链接。编辑文档时自动检测当前文档，查询其父文档和子文档，在编辑器顶部显示面包屑式导航条（含同级文档的上下篇导航），方便文档间快速跳转。

## 功能特性

- **面包屑导航**：从根到当前文档的逐级路径，点击任意层级即可跳转
- **同级导航**：上一篇/下一篇快速切换，附带当前文档序号
- **父文档链接**：点击跳转上级文档
- **下级文档下拉树形面板**：点击"下级文档 (N)"按钮弹出下拉面板，以树形层级展示子文档；有下级的节点显示展开箭头，点击后通过思源 API 懒加载逐级钻取浏览，点击面板外部自动关闭
- **过滤下拉树形面板**：仅显示标题命中过滤关键词（默认 `["参考"]`，可在 `DocNavSettings.filterKeywords` 中配置，与旧版硬编码行为一致）的子文档；点击面板外部自动关闭
- **反向链接下拉面板**：点击"反向链接 (N)"按钮弹出下拉面板，展示所有引用/提及当前文档的文档（`getBacklink` + `getBackmention` 合并去重，上限 50 条）；面板内置搜索框，输入关键词即时过滤列表并高亮匹配文本，点击条目跳转对应文档，点击面板外部自动关闭
- **文档元数据信息条**：导航栏最右侧展示当前文档的创建时间（短日期）、最后更新时间（相对时间）与块数统计（`getDoc` + SQL 块数统计）；hover 时显示完整时间戳与文件大小

## 技术实现

- **数据源**：`getPathByID` / `listDocsByPath`（层级）、`getBacklink` / `getBackmention`（反链）、`getDoc` + SQL（元数据）
- **缓存**：`DocNavigationCache` 内存缓存，TTL 60s，LRU 驱逐上限 20 条；层级/面包屑/同级/反链/元数据各用独立槽位，`clearAll()` 统一清理
- **时间格式化**：`utils.ts` 提供 `formatRelativeTime`（7 天内显示"X 天前"，之后回退短日期）、`formatShortDate`、`formatFullTime`
- **下拉外壳共享**：`styles/_dropdown-shell.scss` 提取触发按钮/面板/过渡动画通用样式，供同级/下级/反向链接三个下拉组件复用
