# imageCreation — 图片生成

统一的图片生成工具，支持文章封面和代码图片两种模式。

- **文章封面**：标题/关键字/摘要输入、12 种封面风格（极简/科技/杂志/导图/国风/扁平/涂鸦/终端/8bit/漫画/像素/日式RPG）、6 种尺寸预设、AI 关键字提取
- **封面增强**：偏好持久化（尺寸/风格/水印/主题色/Logo/导出格式）、自定义主题色、Logo 角标、水印位置与透明度、PNG/JPEG/WebP 导出、AI 全自动封面（AI 推荐 + 4 个随机组合候选）、一键换风格
- **代码图片**：代码/文字输入、20 种语言高亮、6 套高亮主题、14 种风格、双主题、等宽字体选择、装饰/自定义底色/背景图、PNG/JPEG/WebP 导出（1x/2x/3x）、复制 HTML、灵感模式随机候选、偏好持久化
