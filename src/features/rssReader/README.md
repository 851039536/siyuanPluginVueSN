# RSS 订阅

订阅和管理 RSS/Atom 源，在右侧边栏阅读文章。注册自定义 RSS 图标，以 Dock 面板呈现，支持添加/删除订阅源、浏览文章列表、阅读文章内容。

## 平台支持

移动端可用。主视图与文章详情本来就是「列表 → 详情」单视图切换，无需改动；原本 hover 显形的按钮在窄屏改为常驻。

密度按 GitHub/Primer 口径（见 [`docs/参考/mobile-ui-density.md`](../../../docs/参考/mobile-ui-density.md)）：
控件视觉保持 24–36px、触摸命中区用透明伪元素扩到 40px（不占布局），正文 14px / 元信息 12px；
工具栏约 40px、筛选胶囊 28px、订阅源行 44px。文章卡片不再为收藏按钮单开底栏（并入标题行右侧），
列表摘要移动端限 1 行，详情页看全文。移动端断点同时匹配「粗指针且无 hover」，横屏手机（视口 ≥ 769px）
不会退回桌面尺寸。文章列表的工具栏在滚动容器内吸顶；正文宽表格横向滚动、图片限宽、超长串断行；
WebView 不提供 `speechSynthesis` 时朗读按钮直接隐藏。

网络抓取沿用「直连 → 公共 CORS 代理」fallback 链。移动网络下若全部尝试失败，错误信息会逐项列出每次尝试的原因；
暂未接入内核 `forwardProxy`，如需彻底规避移动端网络差异可后续补充为链尾尝试。
