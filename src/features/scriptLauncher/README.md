# 脚本启动器

管理和运行自定义脚本（Python、Bash、PowerShell、Node.js、Batch）的 Dock 面板工具。支持脚本的增删改查、按语言分类筛选、搜索以及终端式输出显示。脚本文件存储在插件数据目录中，元数据通过 TypedStorage 持久化。

## 可选设置：内置监听

面板工具栏下方提供「内置监听」开关（设置持久化，无需重启）：

- **开启后点击运行**：不再调用系统默认程序弹出独立窗口，而是隐藏控制台窗口（`windowsHide` + `pythonw` 等），在面板内的「运行监控」区显示启动信息、实时输出与运行状态。
- **监控区可折叠**：点击标题可收起/展开，保留顶部「运行中 N」计数徽标。
- **显示已启动**：每个进程显示名称、语言、启动时间、状态点（运行中/已结束/已停止/错误）、命令与 stdout/stderr 输出。
- **不使用时可以关闭进程**：每个进程卡片提供「停止」按钮（Windows 下 `taskkill /T /F` 结束进程树），也可一键停止全部；已结束的条目可「关闭」移除。
- 插件卸载时自动停止仍在运行的内置监听进程。
