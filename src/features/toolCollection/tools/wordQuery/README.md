# 单词查询

工具合集内置的 AI 辅助面板，通过顶部标签切换 6 种模式（单词查询 / 长文翻译 / 编程翻译 / 注释生成 / 代码解释 / 正则生成）。所有模式共用插件设置中的 AI API 配置（`getApiConfigFromPlugin`），输入后 2 秒自动触发，也可手动点击按钮执行。

## 已支持功能

| 模式 | 说明 |
|------|------|
| 单词查询 | 查询英文单词/中文词语的详细释义、音标、谐音、例句；英/美式发音切换、查询后自动朗读 |
| 长文翻译 | **自动识别原文语言并译为另一种语言**（中文 → 英文、英文 → 中文），支持 7 语种互译，超长文本自动分段翻译 |
| 编程翻译 | 中文→英文代码命名翻译，支持驼峰/帕斯卡/下划线等 5 种风格 |
| 代码注释 | 为代码生成 JSDoc/行注释/块注释等风格注释 |
| 代码解释 | 分析代码功能、复杂度及优化建议 |
| 正则生成 | 根据自然语言描述生成正则表达式，支持测试匹配 |

## 长文翻译的语言识别

翻译面板的源语言默认为「自动检测」，目标语言默认为「自动（译为另一种语言）」：

- 本地按「汉字数 vs 拉丁词数」判定主语言（有假名判日文、有谚文判韩文）
- 目标语言随检测结果自动翻转：识别为中文 → 译成英文，识别为英文 → 译成中文
- 面板内实时显示「检测到：中文」「译为：英文」，避免用户对译向产生歧义
- 源语言与目标语言相同时给出冲突提示，并提供「改为另一种语言」的一键纠正
- 交换按钮按**解析后的实际语言**反向，未能识别语种时给出提示

> 检测与推导逻辑为纯函数，位于 `utils/languageDetect.ts`，配有 `languageDetect.spec.ts` 单测。

## 交互约定

- 单词查询：输入即查（2 秒防抖），Enter 立即查询；结果区按「单词 / 音标 / 释义 / 谐音 / 例句」表格化展示
- 复制：结果区「复制」下拉可单独复制音标、释义、英文、谐音、例句
- 导出：下载 Markdown 文件（`<单词>.md`），而非仅写入剪贴板
- 长文翻译：输入上限 8000 字符，超过单次请求长度（2000）时按段落分段翻译并拼接，翻译中显示 `分段翻译中（n/m）` 进度
- 连续输入时旧请求会被取消（`AbortController` + 请求序号），避免旧结果覆盖新结果

## 配置项

- `enableWordQuery` — 启用/禁用单词查询功能（超级面板开关）

## 扩展建议

以下方向可供未来迭代参考：

1. **发音 API 集成**：接入真实的 TTS API（如 Web Speech API 或第三方服务）替代 `speechSynthesis`，提升发音准确性
2. **历史记录**：持久化查询历史，支持近期查询快速回看
3. **批量查询**：支持粘贴单词列表批量查询并导出为表格
4. **快捷粘贴**：监听剪贴板变化，自动触发查询（适合阅读外文资料场景）
5. **悬浮查询**：集成 `floatingToolbar`，选中文本后一键弹窗查询
